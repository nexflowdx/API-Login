# Fase 0 — Planejamento

## Objetivo
Entender o projeto completo antes de escrever qualquer código: o que é uma API, o que será construído, e como FastAPI, PostgreSQL e JWT trabalham juntos.

## Motivação
Evitar codar sem entender o fluxo geral — planejar antes reduz retrabalho e ajuda a tomar decisões de arquitetura mais conscientes nas fases seguintes.

## Pré-requisitos
Nenhum — fase conceitual, sem código.

## Passo a passo
1. Entendimento do papel da API como intermediária entre cliente e banco de dados.
2. Mapeamento do fluxo completo de login: cadastro → login → geração de JWT → validação em rotas protegidas.
3. Entendimento de como FastAPI, PostgreSQL e JWT se conectam na arquitetura do projeto.

## Como validar a configuração
Não há configuração técnica nesta fase — a validação é conceitual: conseguir explicar o fluxo completo de cadastro e login sem consultar material.

## Lições aprendidas
Entender o fluxo antes de codar deixou as fases seguintes mais claras — cada arquivo criado já tinha um propósito conhecido de antemão.
